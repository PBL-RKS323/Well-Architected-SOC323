2. PERAN DI DALAM APLIKASI (BUKAN PERAN TIM)
=====================================================================================
Aplikasi punya 3 peran (models/user.py, tabel IZIN):
  - Admin     = pemilik / pengelola toko. Semua izin: produk, pesanan, laporan, kelola pengguna.
  - Staf Toko = karyawan toko. Kelola produk & pesanan saja (tidak bisa laporan & kelola pengguna).
  - Pelanggan = pembeli. Daftar sendiri lewat /register, belanja, checkout, upload bukti transfer.
Spesifikasi PBL hanya mewajibkan Admin & Customer; Staf adalah nilai tambah (RBAC lebih rinci).

Siapa memerankan apa saat demo:
  - Pedro   -> login sebagai Admin  (CRUD produk, dasbor admin)
  - Ihsan   -> login sebagai Staf   (System Analyst: bukti acceptance criteria -> menu Laporan/Pengguna
               tidak ada, akses /admin/pengguna ditolak dan tercatat ACCESS_DENIED di logs/security.log)
  - Intan   -> login sebagai Pelanggan (register, katalog, detail produk, keranjang)
  - Ripasha -> QA memegang akun uji untuk KETIGA peran (pelanggan, staf, admin), karena tugas QA justru
               memastikan setiap peran hanya bisa membuka halamannya sendiri.
  - Yudha   -> membuka & menutup presentasi, GitHub, struktur folder, Blueprint.

6. CARA MENJALANKAN DI LOCALHOST (WINDOWS)
=====================================================================================
CARA CEPAT (SATU PAKET, DIPAKAI UNTUK LAPTOP DEMO):
  Syarat: Python 3.11-3.13 terpasang (centang "Add python.exe to PATH" saat instal).
  1. Unduh repo (git clone, atau Code > Download ZIP lalu ekstrak).
  2. Klik dua kali setup.bat -> pilih [1] PostgreSQL portabel -> isi data akun admin.
     (PostgreSQL diunduh otomatis +/- 330 MB ke folder .lokal/, tanpa installer. Cukup sekali.)
  3. Klik dua kali jalankan.bat -> browser terbuka ke http://127.0.0.1:5000
     Jangan tutup jendela hitamnya selama demo. Selesai: tekan Ctrl+C.
  Saran: jalankan setup.bat di laptop demo SEHARI SEBELUM demo (butuh internet untuk unduhan).

CARA MANUAL (KALAU INGIN PAHAM TIAP LANGKAH):
  git clone https://github.com/PBL-RKS323/Well-Architected-SOC323.git
  cd Well-Architected-SOC323
  git checkout development
  python -m venv venv
  venv\Scripts\activate
  pip install -r requirements.txt
  copy .env.example .env
     -> buka .env, isi SECRET_KEY (hasil: python -c "import secrets; print(secrets.token_hex(32))")
     -> ganti baris DATABASE_URL menjadi: DATABASE_URL=sqlite:///toko_lokal.db
  flask db upgrade          (membuat semua tabel dari folder migrations/)
  flask seed-admin          (membuat akun admin, kata sandi wajib: huruf besar+kecil+angka+simbol)
  flask seed-katalog        (mengisi 17 produk contoh + fotonya)
  flask run --debug         -> buka http://127.0.0.1:5000

Kenapa di localhost awalnya tidak ada produk/gambar?
  Produk & foto di web live tersimpan di database PostgreSQL dan folder static/uploads di server OCI.
  Keduanya sengaja TIDAK masuk GitHub (.gitignore). Yang ada di GitHub hanya kode + 17 foto contoh di
  seed/foto/. Jadi setiap laptop harus menjalankan "flask seed-katalog" sendiri.

Database lokal:
  - SAAT DEMO WAJIB PostgreSQL/MySQL (spesifikasi: "Wajib SQL (MySQL, MariaDB, atau PostgreSQL)").
    Pakai setup.bat pilihan [1] (PostgreSQL portabel). Jawaban jika ditanya: "PostgreSQL 17,
    driver psycopg2-binary, tabel dibuat dari migrations/ dengan flask db upgrade".
  - SQLite hanya untuk latihan di laptop sendiri (setup.bat pilihan [3]).
  - Database tidak ditulis di requirements.txt. requirements.txt hanya untuk library Python
    (driver psycopg2-binary & PyMySQL sudah ada di sana). Struktur tabel ada di migrations/.

Pembayaran:
  Spesifikasi PBL: "Upload transfer" + "Approval bukti bayar" -> sudah ada (transfer manual: pelanggan
  upload bukti di /pesanan/<kode>, admin setujui di /admin/pesanan). Opsi QRIS/E-Wallet Midtrans di
  checkout masih berlabel "SEGERA" (belum ada integrasi). Midtrans Sandbox hanya opsional (nilai tambah),
  dan pembayaran tidak termasuk 5 fitur yang dinilai di ATS.
